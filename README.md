# 飞书周报 Skill

从本人飞书消息、项目排期及相关 Codex 任务中整理有依据的周报，保留 Rainbow 周报流程与写作习惯。

支持周一规划、每日收尾、周五总结、只生成草稿、写入指定文档、按评论修订与依据核查。周一仅填写计划；完成状态必须有依据；保留用户手工编辑和原模板结构。

## 安装

将 `skills/lark-weekly-report` 整个目录复制到 `~/.codex/skills/`。已有同名 skill 时先备份，再合并个人配置。

依赖已安装并授权的 `lark-cli` 及其版本匹配的内置服务 skills；本仓库不包含 CLI、账号凭据、私人文档或消息记录。在 Windows 上需要能访问系统凭据存储的主机执行环境。Codex 任务证据需要对应的任务读取工具。

复制 `references/source-profile.example.md` 为同目录的 `source-profile.local.md`，填写自己的模板、历史样例、排期表、项目群及固定职责。该文件已被 Git 忽略。未配置的资源不能视为已验证；缺少写入目标或模板时先补齐，其他缺失来源应如实说明。

Rainbow 三列表格是附带的格式约定；当前请求指定的模板优先。私人模板与图片不随仓库分发，新使用者需要提供可访问的模板。

## 使用示例

- `使用 $lark-weekly-report，根据上周完整消息整理本周计划，先给草稿。`
- `使用 $lark-weekly-report，把今天的完成情况更新到这份周报：<文档链接>。`
- `使用 $lark-weekly-report，核查本周总结的依据，不修改文档。`

每日 19:00、周五总结是流程建议，安装 skill 不会自动创建定时任务。只有用户明确要求时才单独配置自动化。本 skill 不发送或回复飞书消息。

## 检查

`scripts/preflight.ps1` 在主机环境核验用户身份，并可检查已有 JSON 采集文件的 UTF-8、JSON 及 API 状态。它会访问真实的登录状态；发布包仅做静态和模拟输入验证，不代表真实账号或文档写入已通过测试。
